DRO files marked _(capture)_ were recorded live through DOSBox.

## Adding more songs

1. Download a `.zip` pack from [vgmrips.net/packs/chip/ym3812](https://vgmrips.net/packs/chip/ym3812)
   or [vgmrips.net/packs/chip/ymf262](https://vgmrips.net/packs/chip/ymf262)
2. Extract the `.vgz` files into `songs/`
3. Run `.\tools\vgz2dro.exe in.vgz out.dro`
4. Run `powershell -File tools\regen_songs.ps1`

Or add new entries to `tools\download_packs.ps1` and run it to automate all steps.
